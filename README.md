# Bright Store — متجر برايت للخيوط

متجر كامل (واجهة + API + قاعدة بيانات) لبيع منتجات برايت بالقطاعي ونصف الجملة والجملة.

## التشغيل
```bash
npm install
cp .env.example .env     # عدّل JWT_SECRET وبيانات المدير
npm start                # http://localhost:3000
```
أول تشغيل يُنشئ حساب المدير ومنتجات برايت (أسعار 01/04/2026) و36 لوناً تجريبياً.
> لو شغّلت النسخة القديمة من قبل: احذف ملف `store.db` لإعادة البناء.

## الجديد
شراء كضيف بدون حساب • ألوان مخصصة لكل منتج • مواصفات وصور متعددة • شحن حسب المحافظة (وشحن مجاني فوق مبلغ) • تأكيد الطلب برقم + واتساب • إشعار تيليجرام فوري • فلترة وتصدير الطلبات Excel • تقارير (منتج/عميل/يوم/محافظة) • سجل تعديلات الأسعار والمخزون • إيقاف منتج مؤقتاً • نسخة احتياطية. للنشر: `DEPLOY.md`.
> الترحيل تلقائي: شغّل النسخة الجديدة على نفس `store.db` وسيُحدَّث الهيكل دون فقدان بيانات.

## النظام
- **الأسعار:** لكل منتج 3 أسعار. يُحتسب السعر تلقائياً حسب إجمالي كمية المنتج في السلة (كل ألوانه معاً): أقل من 50 قطاعي، 50–99 نصف جملة، 100+ جملة. الحدود قابلة للتغيير من الإعدادات. السلة تقترح على العميل «أضف X لتحصل على سعر أقل».
- **الألوان:** قائمة ألوان مشتركة (كود + اسم + لون). العميل يبحث ويختار عدة ألوان بكميات في نفس المنتج. الاستيراد بالجملة من لوحة التحكم (سطر لكل لون: `كود,اسم,#لون`).
- **لوحة التحكم:** إحصائيات، إضافة/تعديل/حذف المنتجات (مع صور)، تعديل الأسعار مباشرة من الجدول، رفع/تخفيض كل الأسعار بنسبة، إدارة الألوان، الطلبات (حالة الطلب وحالة الدفع)، وإعدادات الدفع.
- **الدفع:** عند الاستلام، أو محفظة إلكترونية، أو إنستا باي (رقم + QR تضعها من الإعدادات). العميل يحوّل ثم يكتب رقم العملية، والطلب يظهر «بانتظار المراجعة» حتى تؤكده أنت.
- **المخزون:** اختياري لكل منتج (فارغ = غير محدود). الإلغاء يرجّع الكمية.

## الأمان
bcrypt، JWT، حد لمحاولات الدخول، Helmet + CSP، SQL محضّر، الأسعار والمخزون تُحسب على الخادم داخل transaction.

## النشر
`docker build -t bright-store . && docker run -p 3000:3000 --env-file .env -e DB_FILE=/data/store.db -v $(pwd)/data:/data bright-store`
خلف HTTPS، وبـ volume دائم لقاعدة البيانات، ونسخ احتياطي دوري لملف القاعدة.

## لاحقاً
بوابة دفع بالبطاقة (Paymob)، تكلفة الشحن حسب المحافظة، استرجاع كلمة المرور، إشعارات واتساب للطلبات.
